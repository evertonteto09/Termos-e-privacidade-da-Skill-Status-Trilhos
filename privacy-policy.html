Política de Privacidade – Status Trilhos

A Skill Status Trilhos foi desenvolvida para fornecer informações sobre a situação operacional das linhas do sistema metroferroviário do Estado de São Paulo.

Informações utilizadas

A Skill utiliza dados públicos relacionados à operação do sistema metroferroviário, fornecidos pela ARTESP (Agência Reguladora de Serviços Públicos Delegados de Transporte do Estado de São Paulo).

Os dados são utilizados exclusivamente para consultar e apresentar informações sobre a situação operacional das linhas.

Linhas favoritas

A Skill oferece uma funcionalidade de linhas favoritas, que permite ao usuário cadastrar linhas para facilitar consultas futuras.

Quando essa funcionalidade é utilizada, as linhas escolhidas pelo usuário são armazenadas para que a Skill possa recuperá-las posteriormente e fornecer o status das linhas favoritas.

O usuário pode adicionar, consultar, remover individualmente ou excluir todas as suas linhas favoritas por meio dos comandos disponíveis na Skill.

As informações relacionadas às linhas favoritas não são utilizadas para fins comerciais.

Compartilhamento de informações

A Status Trilhos não vende, comercializa ou compartilha as informações das linhas favoritas dos usuários com terceiros para fins comerciais.

A Skill utiliza os serviços necessários da plataforma Amazon Alexa para seu funcionamento e para o armazenamento das preferências associadas à funcionalidade de linhas favoritas.

Finalidade

As informações utilizadas pela Skill têm como única finalidade fornecer funcionalidades relacionadas à consulta do status das linhas metroferroviárias e ao gerenciamento das linhas favoritas do usuário.

A Status Trilhos não solicita informações como nome, endereço, telefone ou e-mail para utilização de suas funcionalidades.

Alterações nesta política

Esta Política de Privacidade poderá ser atualizada caso sejam adicionadas novas funcionalidades ou modificações que alterem a forma como as informações são utilizadas ou armazenadas.

Última atualização: agosto de 2026.
